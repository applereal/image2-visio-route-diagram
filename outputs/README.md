# 蔬菜集运机技术路线图

本目录包含“垄作空间约束下自走式蔬菜集运机田间适应性研究”技术路线图。

- `vegetable_transporter_technical_route.svg`：可直接插入论文、汇报或继续编辑的矢量路线图。
- `vegetable_transporter_route_plan.json`：路线阶段与研究输出的结构化计划，可作为 Visio JSON 计划的内容底稿。

路线主线为：作业约束与研究问题 → 理论基础与参数获取 → 整机概念设计 → 田间适应性理论分析 → 现场试验与综合验证 → 参数范围、稳定性评价方法和田间适应性判据。图中绿色虚线表示现场试验结果对设计参数和适应性判定的反馈闭环。
